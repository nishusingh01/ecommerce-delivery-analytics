# 📊 E-Commerce Delivery Analytics Dashboard

An interactive Excel dashboard built to analyze e-commerce delivery data and generate actionable business insights.

---

## 🔧 Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers & Filters

---

## 📌 Project Overview

This project focuses on analyzing e-commerce delivery performance using Excel.
The dashboard helps in understanding order trends, delivery efficiency, and operational performance through interactive visualizations.

---

## 📊 Key Features

* Interactive dashboard with slicers
* Dynamic pivot tables and charts
* Region-wise and category-wise analysis
* Delivery performance tracking
* Clean and user-friendly layout

---

## 📈 Key Insights

* Order distribution across different regions
* Delivery delays and performance trends
* Category-wise product performance
* Monthly and overall order analysis
